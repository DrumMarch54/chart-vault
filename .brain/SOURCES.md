# Numerology reference materials (Google Drive)

All the teaching material behind this app lives in the owner's Google Drive.
Read it yourself with the Google Drive tools (`search_files`, `read_file_content`);
never ask the owner where it is or to paste from it. Search by `parentId = '<id>'`
to list a folder. OCR'd PDFs read as plain text. Numbers like `13` mean `13/4`
(compound/digit sum); transcripts spell them "15,6", "15 6", "fifteen six".
